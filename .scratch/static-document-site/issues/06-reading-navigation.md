# 06: 以閱讀進度與手機章節面板定位段落

**What to build:** 讀者捲動長文時能掌握目前段落與進度；手機上不必返回開頭即可開啟章節面板並跳到需要的段落。

**Blocked by:** 03: 依定稿版面閱讀與接續文章

**Status:** completed

- [x] 桌面固定目錄依閱讀位置標示目前段落，頁頂進度線隨捲動更新；文末收尾帶不遮擋目錄。
- [x] 手機文章開場捲出畫面後才出現閱讀列，顯示目錄入口、目前段落及進度，過長段落名以省略號處理。
- [x] 使用原生 dialog 呈現帶序數的章節面板並標示目前段落；開啟後焦點移入，關閉可回復合理焦點，鍵盤與 Escape 可操作。
- [x] 選取章節後面板關閉並定位到正確段落，定位後鍵盤閱讀可接續於目標，標題不被閱讀列遮住。
- [x] 減少動態時無動畫；停用 JavaScript 後靜態目錄與文章連結仍可使用，不因互動增強失效而遮住正文。
- [x] 以正式產物在 1440×900 的交易與隔離及 390×664 的手機文章驗證捲動、焦點、段落與進度，包含根路徑與子路徑及淺深外觀。
