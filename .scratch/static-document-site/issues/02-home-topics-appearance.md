# 02: 從定稿首頁與主題頁找到閱讀起點

**What to build:** 讀者能透過定稿首頁與主題索引選擇閱讀起點，在桌面或手機切換主題及外觀；全站具備可重用的頁首、頁尾、字型與外觀。

**Blocked by:** 01: 公開文件可透過穩定網址閱讀

**Status:** completed

- [x] 依結構 A 與「8 海報封面」v6 的設計交接實作首頁與主題頁：鈷藍開場、品牌簡介、主題列或文件列、序數、摘要、文件數及閱讀起點均來自現有公開內容。
- [x] 首頁主題入口、閱讀起點、主題頁文件連結可抵達正確文章，排列遵循主題索引；中英文起點文字間距正確。
- [x] 共用頁首含品牌、主題導覽與搜尋入口，手機改用切換主題下拉選單；搜尋入口預留給 ticket 07，完成前不提供無作用的互動按鈕。
- [x] 自行託管並子集化 Noto Sans TC 與 Space Grotesk，保留授權；使用定稿色彩 token、字級、間距、斷點及頁尾，不載入外部字型 CDN。
- [x] 系統、淺色、深色外觀皆可選擇，預設跟隨系統；在兩種明暗環境下實際驗證文字、焦點及主題導覽。
- [x] 第一個焦點是跳至內容，鍵盤能操作主題及外觀選單，焦點可見、觸控目標符合設計交接，減少動態時關閉動畫。
- [x] 透過正式產物在根路徑及子路徑驗證 390 與 1440 寬度的首頁、主題頁、字型及導覽，整頁無水平溢出。
