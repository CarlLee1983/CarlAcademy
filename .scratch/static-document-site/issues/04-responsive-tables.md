# 04: 在手機閱讀表格並切換比較方式

**What to build:** 讀者在手機可用卡片閱讀表格，也能切回原表格比較欄列；桌面保留寬表格閱讀空間，整頁不因寬內容溢出。

**Blocked by:** 03: 依定稿版面閱讀與接續文章

**Status:** completed

- [x] 表格欄名資料及工具列結構在建置時輸出；手機預設卡片以第一欄為標題、其餘欄名為標籤，停用 JavaScript 仍能閱讀。
- [x] 工具列顯示實際欄數與列數，切換原表格比較後可橫向捲動且工具列位置穩定；切回卡片內容不遺失。
- [x] 桌面表頭、第一欄、數字樣式及表格延伸符合設計交接，寬度依文章容器計算；手機原表格可延伸至螢幕兩側但不造成整頁水平溢出。
- [x] 以交易與隔離的隔離等級表格驗證桌面寬於正文欄且每列不換行；以容器編排與運算容量驗證 390×664 的卡片與原表格切換。
- [x] 在正式產物、兩種部署路徑及淺深外觀驗證內容與切換；鍵盤可操作、焦點可見，無 JavaScript 時不暴露無作用的控制。
