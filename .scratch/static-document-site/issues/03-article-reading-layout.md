# 03: 依定稿版面閱讀與接續文章

**What to build:** 讀者能在定稿文章版面閱讀正文、查看本文目錄與本主題文件，並從文末接續前後篇；手機與停用 JavaScript 時仍有完整閱讀入口。

**Blocked by:** 02: 從定稿首頁與主題頁找到閱讀起點

**Status:** completed

- [x] 沿用共用外觀與字型，依定稿呈現麵包屑、主題及文件序號、鈷藍開場、提要、章節標題、正文及全寬文末收尾帶；不帶入原型樣張導覽、參數路由或原型標示。
- [x] 桌面呈現固定本文目錄與可展開的主題文件清單、查證日期；目錄錨點及前後篇依既有索引正確運作，第一篇與最後一篇不出現無效連結。
- [x] 手機開場只放圖號與標題，提要成為正文導言，隱藏麵包屑，保留可收合的文件與本文目錄。
- [x] 以實際文章驗證中文標點旁的粗體、數字範圍、表格、程式碼與標題錨點呈現正確；停用 JavaScript 後正文、靜態目錄及基本導覽仍可使用。
- [x] 在 1440×900 開啟 Elastic Load Balancing 與 CloudFront 文件，首屏正文起點約在 610px 以內；正文寬度、行高、目錄位置及文末導覽符合定稿。
- [x] 在 390 與 1440 寬度、淺深外觀及根路徑與子路徑驗證代表文章，收尾帶不遮擋目錄，錨點定位不被固定介面遮住，減少動態設定生效。
