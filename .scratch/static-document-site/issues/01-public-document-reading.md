# 01: 公開文件可透過穩定網址閱讀

**What to build:** 讀者能在一般靜態伺服器上直接開啟首頁、主題索引及現有文章，沿文件連結與段落錨點閱讀；作者仍只維護原有 Markdown。此張提供可驗證的基本網站，定稿畫面由後續 tickets 完成。

**Blocked by:** None (can start immediately)

**Status:** completed

- [x] 採用已確認的 Astro 靜態輸出與 Content Collections，從公開主題載入及驗證內容；頁面共用內容查詢與網址規則，不維護另一份文章副本。
- [x] 首頁、5 個主題索引與目前 64 篇文章皆有可讀的靜態頁面；覆蓋範圍從實際公開清單推導，不將 64 設為上限。
- [x] 主題索引及文章遵循既有閱讀安排；既有 Markdown 相對連結轉成英文分層、尾斜線的公開網址並保留段落錨點，跨主題連結可用，直接開啟及重新整理深層網址成功。
- [x] 中文標題變動不改公開網址；必要資料缺漏、網址衝突及無效站內目標不會靜默通過建置驗證，提供能定位問題的錯誤。
- [x] 內部規劃、詞彙表、ADR、設計交接及代理設定不進入頁面、導覽或原始檔輸出；公開文章連往內部文件的內容改成適合讀者的導覽。
- [x] 建立正式建置產物的驗收入口，以一般靜態伺服器驗證根路徑及非空子路徑的頁面、資源、連結與錨點，不依賴平台特有的副檔名補全。
- [x] 停用 JavaScript 仍可閱讀正文並使用基本連結；記錄建置、預覽及驗收命令與結果。
