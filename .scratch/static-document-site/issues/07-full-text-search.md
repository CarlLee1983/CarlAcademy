**What to build:** 讀者能從首頁或全站搜尋入口搜尋公開文章標題與正文，依主題、標題及摘要選擇文章，並在載入失敗時重試。

**Blocked by:** 02: 從定稿首頁與主題頁找到閱讀起點

**Status:** completed

- [x] 對完整公開 HTML 建立 Pagefind 索引，驗證所選版本與建置配置具備中文斷詞能力，排除導覽等重複介面文字及內部管理內容。
- [x] 全站搜尋入口與首頁表單均能開啟可用的搜尋對話框，呈現輸入、結果數、主題、文章名稱及命中摘要，結果導向正確文章。
