# 05: 閱讀、換行與複製程式碼

**What to build:** 讀者可閱讀超寬程式碼、切換換行並複製原文；既有框線圖保留排版，寬內容只在自身容器捲動。

**Blocked by:** 03: 依定稿版面閱讀與接續文章

**Status:** completed

- [x] 建置時輸出程式碼工具列與語言標籤，使用定稿淡底、墨色文字、等寬字體及鈷藍邊，不套用深色語法主題。
- [x] 只有內容超寬時提供換行控制；尚未捲到底時顯示右緣捲動提示，捲到底或無溢出時不顯示誤導提示，切換後依實際內容更新。
- [x] 複製取得原始程式碼及正確換行，工具列文字不混入複製結果；瀏覽器拒絕複製時不得顯示成功。
- [x] 手機程式碼框依設計延伸至螢幕兩側，桌面依文章容器延伸；無 JavaScript 仍能閱讀並捲動內容。
- [x] 現有框線圖以原排版過渡呈現並可局部橫向捲動，不選擇 SVG 工具、不在此張全面重繪圖解。
- [x] 以正式產物的實際超寬與一般程式碼驗證桌面、手機、鍵盤、淺深外觀及兩種部署路徑，確認原文複製、換行、提示及整頁無水平溢出。
