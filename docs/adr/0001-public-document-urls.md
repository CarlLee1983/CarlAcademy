# 公開文件網址與 Markdown 來源分離

CarlAcademy 保留既有 `docs/` Markdown 作為唯一文章來源與本地閱讀入口，但公開網站採用穩定的英文分層網址：例如 `docs/linux/README.md` 對應 `/linux/`，`docs/linux/what-is-linux.md` 對應 `/linux/what-is-linux/`。建置時統一轉換相對連結並保留段落錨點，產生可由一般靜態伺服器直接提供的頁面；不將 `.md` 檔案路徑或託管平台特有的副檔名補全行為作為公開網址契約。

這項決定增加網址映射與連結檢查的成本，換取 Markdown 可直接閱讀、公開網址不隨中文標題變動，以及更換靜態託管平台時的可預期性。網站發布後，變更既有公開網址須保留舊網址轉址；目前尚未發布，因此不假定已有外部網址需要遷移。部署於子路徑時，公開路徑須套用該次建置的 base path。
