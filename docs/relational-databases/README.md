# 關聯式資料庫共通知識

關聯式資料庫把資料整理成有明確欄位與規則的資料表，再用查詢組合資料、用約束與交易維護狀態。
本主題關心如何表達事實、如何避免不一致，以及如何理解查詢的成本；不以特定語言的 ORM 寫法作為入口。

## 共通概念與產品差異

關聯模型、鍵、函數相依與一致性問題是共通知識。SQL 是操作資料的語言，並非整個關聯模型；
產品對型別、NULL、隔離與執行計畫的實現不完全相同。
需要具體語法時，本系列明確採 **PostgreSQL 18**；不將其行為當成所有資料庫的預設。

查證日期：2026-11-02。各篇直接連結查閱過的 PostgreSQL 18 官方手冊、Microsoft Learn 與 Berkeley、SJSU 課程筆記；
來源依版本路徑固定，課程筆記則以查證當日頁面為準。**本系列只做文件查證，未啟動資料庫、執行 SQL、重現並行排程或量測效能。**
預期結果是依文件與自創資料推導，不能當成實測紀錄。

這裡不涵蓋安裝、框架串接、備份還原、複寫、高可用、分片或雲端資源建立。
後續若需要產品操作，應連回共同概念，再獨立查證版本與驗證操作。
